# Tools

Tools is a small static site of productivity utilities.

## What’s included

- **Ink** — a markdown renderer with live preview, Mermaid support, and HTML/PDF export
- **Cue** — a script-notes scratchpad that pops out into a floating, always-on-top window
- **Flux** — a focus timer with presets, focus mode, and picture-in-picture support

## Project structure

- `index.html` — landing page
- `markdown-render/` — Ink
- `cue/` — Cue
- `timer/` — Flux

## Usage

Open `index.html` in a browser, or serve the repository with any static file server.

The site is also configured for the custom domain `tools.theharshitsingh.com`.

## Notes

- No build step is required.
- The tools are implemented as standalone HTML files with embedded CSS and JavaScript.
